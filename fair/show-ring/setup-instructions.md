# Custer County Fair — Show Ring Setup Instructions

*Swine / Livestock Show Ring — Build Guide*

## 1. Overview

This is the setup guide for the show ring inside the livestock sale building off 4th St. The stage is fixed and permanent, it never moves. The ring is built around it fresh each fair.

The ring is roundish, not a square-cornered rectangle. Panel-by-panel placement can flex a little to match the ground, but the fixed points below never move.

## 2. Fixed Points (never move)

- Stage — 24'6" wide, permanent, ring is built around it. The 4 sorting show pens (6' each, removable tops) are built into the stage structure itself, not separate equipment. Ring-side access only, for judges to sort animals. No backstage or outside door into them, so the stage/pen unit has to be in place before the rest of the ring closes around it.
- American flag and 4-H flag — mounted at the stage corner
- PA system (2 Fender speakers + mixer) — staged at the announcer corner
- Ribbon board — hangs on the gate near the stage corner
- Photo backdrop banner — fixed to the wall directly opposite the stage

*Bedding note: 50 bags is Matt's set quantity for this ring, not the full 3" depth calculation. At 50 bags, expect roughly 1.3" average depth if spread evenly across the whole floor, or a fuller 3" depth if concentrated in the higher-traffic center/judging area rather than spread edge to edge. If a full 3" across the entire floor is actually needed, budget closer to 118 bags instead.*

## 5. Setup Steps

1. Confirm the stage area is clear, this is your fixed anchor point. Do not move it.
2. Mount the American flag and 4-H flag at the stage corner if not already up.
3. The stage arrives with its 4 sorting show pens already built in, ring-side access only. Confirm they're in place before closing the rest of the ring around it, there's no way to add them after panels go up.
4. Set the Exit gate (4') at the SW corner, against the stage.
5. Working outward from the exit gate, connect the 11 blue panels (10' each) using the pin-and-sleeve hinge joints, following the rough shape shown on the map.
6. Set the Entrance gate (6') centered on the west side, facing the Sheep Shed.
7. Close the loop by connecting the last panel back to the stage's east end.
8. Spread sawdust/shavings across the ring floor, 50 bags total (see Section 4 for depth tradeoff).
9. Set up the PA system (speakers + mixer) at the announcer corner and the ribbon board on the gate near the stage.
10. Confirm the photo backdrop banner is hung on the wall opposite the stage.
