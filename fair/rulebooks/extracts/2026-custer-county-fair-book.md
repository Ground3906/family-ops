# 2026 Custer County Fair Book — Lean Extract

Condensed extract of the county's source-of-truth premium book (2,305-line/13,572-word full conversion of the original .docx). This is the working reference — the full original lives in `fair/rulebooks/archive/2026-custer-county-fair-book.docx`, pulled only on deliberate need per the charter's extract-then-file principle. Volatile specifics (dates, fees, names, weights) are catalogued in full in `volatility-inventory.md` rather than repeated here; this file focuses on rule *structure and content* for comparison purposes.

## Front matter

Fair Schedule (Jul 9–19, 2026 — full table in `volatility-inventory.md` §1). Code of Conduct: prohibited-behavior list (substances, abuse, weapons except shooting sports, property damage, judge contact, ribbon/sticker tampering); disciplinary procedure (notice → evidence → hearing → sanction, sanctions ranging verbal warning through expulsion); protest ($50, 24hr) and appeal ($100, 8hr) process, Fair Board executive panel decision final. Board/staff/superintendent roster (full list in `volatility-inventory.md` §2). Fairgrounds cleanup (mandatory, pre- and post-fair).

## Shooting Sports

General rules incorporate the Colorado 4-H Shooting Sports Rulebook by reference (county book cites `co4h.colostate.edu/ss/ss-rulebook.pdf` — now a dead link, see divergence-map.md's citation-integrity flag). Local scorecard opt-out from Orion (divergence-map.md SHOOT-01). County-specific: competitors must be in good standing with club/county, complete a record book, score ≥75% plus at least a red ribbon to advance. American ribbon system for placings. Two contest days: Firearms (.22 Rifle, Shotgun) and Archery, each with local agent Reggie Foster.

## 4-H Family Consumer Science & General Projects

Danish System judging. Champion ribbon → CSF qualification + state fair quality sticker (Reserve Champion promoted if Champion declines). Age divisions Junior/Intermediate/Senior (8-10/11-13/14-18). Premiums $8/$5/$3/$2/$2 for Blue through Pink placements. E-record book and display requirements incorporated by reference from CO 4-H (link also dead, live replacement archived as `co4h-consumer-science-general.md`).

## Market Eligible Livestock (Swine, Beef, Sheep, Goat)

Cross-species general rules: 4-H/FFA membership required, age 8 and not yet 19 as of Dec 31; dress code for showing and sale; mandatory post-weigh-in exhibitor meeting; American ribbon system; care-continuity rule from weigh-in forward with a defined family/mentor assistance carve-out; three-strikes coaching-interference discipline (cumulative across species); unethical-practices ban (4 items, see divergence-map.md ETHICS-01); re-weigh accommodation (2 tries pre-close, see divergence-map.md LIVESTOCK-01).

Species-specific weight windows and check-in/judging dates: full detail in divergence-map.md (BEEF-01, SWINE-01, SHEEP-01, GOAT-01) and volatility-inventory.md §4. Scrapie tags required for sheep and goats. Goat has a unique local weight-gain rule (must gain ≥5 lbs initial-to-final weigh-in).

## Horse

Colorado 4-H Rule Book incorporated by reference for class rules. Stallions prohibited. Showmanship, horsemanship, and written test mandatory for all contestants. Novice/Junior/Senior structure with a walk-trot-only Novice tier. Weighted point system by class size. Full In-Hand/Western/English/Trotting-Gymkhana/Gymkhana class list with Champion/Reserve/Grand Champion award structure.

## Non-Market Eligible Livestock & Small Animal

Llama/Alpaca: enrolled by Apr 15 Add/Drop Date, 8-obstacle minimum performance classes, Costume/Pack/Obstacle/Public Relations/Showmanship class list. Dog: follows CO 4-H Dog Show requirements by reference (link dead, live replacement archived); Danish for obedience + American for showmanship; no bitch in heat; rabies proof required (silent on titer acceptance, see divergence-map.md DOG-01). Breeding Swine/Beef/Sheep/Non-Market Goat: rules and classes set entirely at superintendent/Fair Board discretion, no further detail printed.

## Showmanship & Sale

Companion Animal Master Showmanship (Cat/Poultry/Dog/Llama champions) and Livestock Master Showmanship (Horse/Beef/Swine/Sheep/Goat champions) are separate contests with separate judging criteria (fitting, presentation, appearance, sportsmanship). Livestock Sale: 2-species-plus-1-rabbit-pen exhibitor cap, Grand/Reserve Grand Champions must sell, sale order by committee/board, USDA Wholesome Meat Act incorporated by reference with its own drug-residue provisions. No stated commission % or no-show forfeiture rule (divergence-map.md SALE-01, SALE-02).

Sale-exit mechanics (added 8/8/2026, fairbook pass one reconciliation — carry-forward findings for the parked terminal-sale thread): the book carries **two** exit provisions, not one. Line 734, "Market animals do not have to be sold. However, if sold, the project is terminated. Project termination is defined as the animal may not be exhibited in any other show or competition." Line 736, "Animals cannot be withdrawn from the sale after they have entered the sale ring," which implies withdrawal remains available up to ring entry. Any terminal-sale language must reconcile both. Separately, the mandatory champion sale is broader than a summary reading suggests: line 722 carries only the exception to the two-animal limit, while line 723 stands alone and unconditional, "All Grand and Reserve Grand Champions will sell." Line 737 already assigns trucking, slaughter, and processing of private sale animals to the exhibitor, which bears directly on any board-possession or buyer-designated-destination proposal.

## Open Division

General rules: liability release on entry, one-fair-per-exhibitor-in-state rule with explicit cross-county residency allowance (divergence-map.md OPEN-01), American system 1st–10th placings, 3-entries-per-class cap, $50 protest fee (24hr window, same as general Code of Conduct process). Twelve numbered divisions (100–1200): Baked Goods, Food Preservation, Decorated Baked Goods, Floriculture, Horticulture, Heritage Arts, Scrapbooking, Sewing/Clothing, Jewelry, Visual Arts, Photography, Miscellaneous — each with its own short entry-prep rules and a numbered class list. Decorated Baked Goods judges decoration only, no tasting (divergence-map.md OPEN-02 flags the CSF mismatch).
