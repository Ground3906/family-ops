# Fair Wish List — Estimated Costs

Edelweiss Farms — ballpark figures, not vendor quotes. Printable version: `fair-wish-list.docx` (same directory).

| Item | Estimated Cost | Notes |
|---|---|---|
| Weaver show box (used) | ~$350 | In range for a smaller/hanging model used; new mini hanging boxes run $310–$530 |
| Lamb stand | $150–$300 | Steel fitting stand, new |
| Show lamb clippers | $200–$450 | Fitting machine with sheep head + blades (Wahl/Andis/Lister); basic body clippers run lower, dedicated show fitting machines run higher |
| Buckets (need ~10) | $50–$100 total | Standard 2–3 gal flat-back livestock buckets, ~$5–10 each |
| Water sprayer | $20–$60 | Handheld livestock sprayer/wand |
| Concrete slab (wash rack pad) | $1,500–$4,000+ | Highly dependent on size and whether you hire a pour or DIY |
| Pens (panels/gates) | $80–$150 per panel | Adds up fast — depends on how many linear feet needed |
| Blower | $150–$400 | Livestock show blower (single-motor to dual-motor range) |
| Crocks | $20–$50 per pair | Rubber shoes worn while washing animals — one pair per person washing |
| Washing tote | $20–$50 | Tub/tote to hold shampoo, brushes, etc. |
| Garment bag / clothes rack | $20–$60 | Simple garment bag or portable rack |
| Generator | $400–$1,200 | 2000–3500W portable covers fans/clippers/lights |
| Rooftop AC for trailer | $1,200–$2,500+ installed | Biggest-ticket item on the list by far |

**Flag:** concrete slab, pens, generator, and rooftop AC are the four items that could swing this budget hard depending on scope — worth pricing those out specifically (get real quotes) before totaling a wish-list budget, rather than trusting these ranges.

**Estimate total (1 Weaver box, 1 pen panel, 1 pair crocks):** $4,160 – $9,700

**Adjusted for realistic quantities** (6 pen panels, 3 pairs crocks — one per person typically on wash duty): roughly **$4,600 – $10,700**. Pens and crocks are the two line items priced per-unit rather than as a total — actual quantity needed will move this number.
